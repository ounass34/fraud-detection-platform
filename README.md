# PNT Fraud Detection Platform
Plateforme souveraine open-source de détection et gestion des Pertes Non Techniques.

## Modules
- backend : FastAPI + PostgreSQL/PostGIS + JWT
- frontend-web : React + Vite + Tailwind + Leaflet
- mobile : Expo React Native + SQLite Offline First

## Démarrage
```bash
docker compose up --build
```

Swagger : http://localhost:8000/api/v1/docs
Frontend : http://localhost:5173
